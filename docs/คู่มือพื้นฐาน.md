# คู่มือพื้นฐาน: เว็บนี้ทำงานยังไง (HTML + Node.js + MySQL)

อธิบายโดยใช้เว็บบันทึกไซเคิลไทม์ของเราเองเป็นตัวอย่าง

---

## 1) ภาพรวม: 3 ชั้น เหมือนร้านอาหาร

| ชั้น | ไฟล์ | เปรียบเหมือน | หน้าที่ |
|---|---|---|---|
| HTML / CSS / JavaScript | `public/index.html` | หน้าร้าน + เมนู | สิ่งที่คนเห็นและกดในเบราว์เซอร์ เช่นฟอร์ม ปุ่ม และรายการประวัติ |
| Node.js + Express | `server.js` | พนักงานเสิร์ฟ + ครัว | รับคำสั่งจากหน้าเว็บ ตรวจสิทธิ์ แล้วไปหยิบหรือเก็บข้อมูลให้ |
| MySQL | (ฐานข้อมูล) | ห้องเก็บของ / สมุดบัญชี | เก็บข้อมูลถาวร ปิดเครื่องแล้วก็ไม่หาย |

**กฎสำคัญ:** หน้าเว็บคุยกับ MySQL ตรงๆ ไม่ได้ ต้องผ่าน Node.js เสมอ
(เหมือนลูกค้าเดินเข้าห้องเก็บของเองไม่ได้)

```
[เบราว์เซอร์]  --fetch-->  [server.js]  --SQL-->  [MySQL]
 index.html   <--JSON--    Express      <--แถวข้อมูล--
```

## 2) เกิดอะไรขึ้นตอนกด "บันทึกข้อมูลนี้"

1. **หน้าเว็บ** รวบรวมข้อมูลในฟอร์มเป็น JSON แล้วส่งไปที่เซิร์ฟเวอร์
   ```js
   fetch('/api/entries', {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ pn, op, process, rows, stats })
   });
   ```
2. **server.js** มีโค้ดรอรับคำสั่งนี้อยู่
   ```js
   app.post('/api/entries', (req, res) => {
     const { pn, op, process, rows, stats } = req.body;   // ข้อมูลที่หน้าเว็บส่งมา
     // ... ส่งต่อให้ MySQL
   });
   ```
3. **เซิร์ฟเวอร์สั่ง MySQL** ด้วยภาษา SQL
   ```js
   db.query('INSERT INTO entries (pn, op, process) VALUES (?, ?, ?)', [pn, op, process], ...);
   ```
4. **MySQL** เก็บแล้วตอบกลับ เซิร์ฟเวอร์ส่ง `{ success: true }` กลับไปที่หน้าเว็บ
5. **หน้าเว็บ** ขอรายการใหม่ (`GET /api/entries`) แล้ววาดประวัติใหม่บนจอ

การเปิดดูประวัติก็คือขั้นที่ 5 ส่วนการลบคือ `DELETE /api/entries/รหัส`

| คำสั่ง | ใช้ทำอะไร | ในเว็บเรา |
|---|---|---|
| GET | ขอดูข้อมูล | โหลดประวัติ |
| POST | ส่งข้อมูลใหม่ | บันทึกรายการ, ล็อกอิน |
| DELETE | ลบ | ปุ่ม "ลบรายการนี้" |

3 คำสั่งนี้เรียกรวมๆ ว่า **API** ซึ่งเป็นช่องทางที่หน้าเว็บใช้คุยกับเซิร์ฟเวอร์

## 3) แต่ละชั้นมีอะไร

### SQL / MySQL
- เก็บข้อมูลเป็น**ตาราง** เหมือน Excel: ตาราง `entries` มีคอลัมน์ `id, pn, op, process, rows, stats, createdAt` ฯลฯ
- คำสั่งหลัก 4 ตัว
  ```sql
  SELECT * FROM entries;                          -- ดูข้อมูล
  INSERT INTO entries (pn, op) VALUES ('A', 'OP10'); -- เพิ่ม
  UPDATE entries SET pn = '12105CBZ' WHERE id = 9;  -- แก้ (แบบที่รันแก้ 12105CBZ)
  DELETE FROM entries WHERE id = 9;               -- ลบ
  ```
- **เทคนิค:** ใช้ `?` แทนการเอาค่าไปต่อเป็นข้อความเอง กันคนพิมพ์คำสั่งอันตรายแทรกเข้ามา (เรียกว่า SQL injection)
- **อย่าลืม `WHERE`** ตอน UPDATE / DELETE ถ้าไม่ใส่จะแก้หรือลบ**ทุกแถว**

### Node.js + Express (`server.js`)
- **Node.js** = ตัวที่ทำให้รัน JavaScript นอกเบราว์เซอร์ได้
- **Express** = ชุดเครื่องมือทำเว็บเซิร์ฟเวอร์
- ส่วนสำคัญในไฟล์ของเรา
  ```js
  require('dotenv').config();               // อ่านรหัส DB จากไฟล์ .env
  const db = mysql.createPool({ ... });     // เชื่อมต่อ MySQL
  app.use(express.json());                  // อ่าน JSON ที่หน้าเว็บส่งมา
  app.use(express.static('public'));        // ส่งไฟล์ในโฟลเดอร์ public ให้เบราว์เซอร์
  app.get('/api/entries', ...);             // กำหนดว่าคำสั่งไหนทำอะไร
  app.post('/api/entries', ...);
  app.delete('/api/entries/:id', ...);
  app.listen(3000);                         // เปิดร้านที่ port 3000
  ```
- `req` = สิ่งที่หน้าเว็บส่งมา, `res` = สิ่งที่เราตอบกลับ

### HTML / CSS / JavaScript (`public/index.html`)
- **HTML** = โครง (ช่องกรอก ปุ่ม)
- **CSS** = หน้าตา (สี ขนาด ระยะห่าง)
- **JavaScript** = การทำงาน (กดปุ่มแล้วคำนวณ ส่งข้อมูล วาดรายการ)
  ```js
  const pn = document.getElementById('in-pn').value;  // อ่านค่าที่พิมพ์
  const res = await fetch('/api/entries');            // ขอข้อมูลจากเซิร์ฟเวอร์
  const entries = await res.json();                   // แปลงเป็นข้อมูลใช้งาน
  ```

## 5) ถ้าจะสร้างใหม่ตั้งแต่ศูนย์ (สูตร 7 ขั้น)

1. ติดตั้ง **Node.js**, **MySQL** และ **VS Code**
2. สร้างโฟลเดอร์ แล้วพิมพ์ใน terminal
   ```
   npm init -y
   npm install express mysql2 dotenv
   ```
3. สร้างฐานข้อมูลกับตาราง
   ```sql
   CREATE DATABASE my_app;
   USE my_app;
   CREATE TABLE entries (
     id INT AUTO_INCREMENT PRIMARY KEY,
     pn VARCHAR(100),
     op VARCHAR(50),
     createdAt BIGINT
   );
   ```
4. เขียน `server.js` เล็กๆ ที่มีแค่ GET กับ POST
5. **ทดสอบ API ก่อน**: เปิด `http://localhost:3000/api/entries` ในเบราว์เซอร์ ต้องเห็นข้อมูล JSON
6. ทำ `public/index.html` ที่มีฟอร์ม + `fetch`
7. ค่อยๆ เพิ่มทีละอย่าง: ลบ → คำนวณ → จัดกลุ่ม → export → รหัสผ่าน (แบบที่เราทำกันมา)

## 6) เทคนิคที่ช่วยได้มาก

- **ทำทีละนิดแล้วทดสอบทุกครั้ง** อย่าเขียนรวดเดียวทั้งหมด

- **error ฝั่งเซิร์ฟเวอร์** ดูใน terminal ที่รัน `npm start` และใส่ `console.log(...)` เพื่อดูค่าระหว่างทาง

## 8) ชื่อต้องตั้งให้ตรงกันไหม? (ตอบ: ต้องตรงกันเป็นคู่ๆ)

ข้อมูลเดินทางผ่าน 4 จุด แต่ละจุดต้อง "จับคู่ชื่อ" กับจุดถัดไปให้ตรงกัน **ตัวพิมพ์เล็ก/ใหญ่ก็ต้องตรง** (`pn` ≠ `PN` ≠ `Pn`)

ตัวอย่าง: เส้นทางของค่า P/N ในเว็บเรา

| จุด | โค้ด | ชื่อที่ต้องตรงกับ |
|---|---|---|
| ① HTML | `<input id="in-pn">` | id นี้ต้องตรงกับ ② |
| ② JavaScript (หน้าเว็บ) | `document.getElementById('in-pn').value` | ใช้ id จาก ① |
| ③ JSON ที่ส่งไป | `body: JSON.stringify({ pn: ... })` | ชื่อ key `pn` ต้องตรงกับ ④ |
| ④ Node.js | `const { pn } = req.body;` | รับด้วยชื่อ `pn` จาก ③ |
| ⑤ SQL | `INSERT INTO entries (pn) VALUES (?)` | ชื่อคอลัมน์ต้องตรงกับตารางจริงใน MySQL |

อีก 2 คู่ที่ต้องตรงกัน
- **URL**: หน้าเว็บ `fetch('/api/entries')` ↔ เซิร์ฟเวอร์ `app.get('/api/entries', ...)`
- **Method**: `method: 'POST'` ↔ `app.post(...)` (ถ้าหน้าเว็บส่ง POST แต่เซิร์ฟเวอร์มีแค่ `app.get` จะได้ error 404)

**ไม่จำเป็นต้องตรงกัน** (แต่ตั้งให้ตรงจะอ่านง่าย)
- id ของ HTML (`in-pn`) กับชื่อ key ใน JSON (`pn`) เราแปลงเองใน JS ได้
- ชื่อตัวแปรใน JS ตั้งอะไรก็ได้

**อาการเมื่อชื่อไม่ตรง**
- id ผิด → error `Cannot read properties of null` ใน Console (F12)
- key JSON ผิด → ข้อมูลไปถึงเซิร์ฟเวอร์เป็น `undefined` แล้วบันทึกเป็นค่าว่าง
- ชื่อคอลัมน์ผิด → error `Unknown column 'xxx'` ใน terminal
- URL หรือ method ผิด → error 404 ในแท็บ Network

**เทคนิคตั้งชื่อ**
- ใช้ภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `pn`, `shiftHours`, `createdAt`
- เลือกแบบเดียวแล้วใช้ทั้งโปรเจกต์ (เว็บเราใช้แบบ camelCase: `shiftHours`)
- ตั้งชื่อคอลัมน์ใน DB = ชื่อ key ใน JSON จะได้ไม่ต้องจำสองชุด

## 9) คำสั่งพื้นฐานที่ต้องใช้ (Cheat sheet)

### Terminal (PowerShell ใน VS Code)
| คำสั่ง | ทำอะไร |
|---|---|
| `cd ชื่อโฟลเดอร์` | เข้าโฟลเดอร์ (`cd ..` = ถอยออก) |
| `dir` | ดูไฟล์ในโฟลเดอร์ |
| `npm init -y` | เริ่มโปรเจกต์ใหม่ (สร้าง package.json) |
| `npm install express mysql2 dotenv` | ติดตั้งเครื่องมือ |
| `npm start` | รันตามที่ตั้งใน package.json (ของเรา = `node server.js`) |
| `node ชื่อไฟล์.js` | รันไฟล์ JavaScript |
| `Ctrl + C` | หยุดโปรแกรมที่รันอยู่ |

### Git (เก็บประวัติโค้ด)
| คำสั่ง | ทำอะไร |
|---|---|
| `git status` | ดูว่าไฟล์ไหนถูกแก้ |
| `git add .` | เลือกไฟล์ที่จะเก็บ |
| `git commit -m "ข้อความ"` | บันทึกจุดเซฟ |
| `git log --oneline` | ดูประวัติจุดเซฟ |

### SQL
```sql
SELECT * FROM entries;                         -- ดูทั้งหมด
SELECT pn, op FROM entries WHERE pn = '12105CBZ' ORDER BY id DESC;  -- กรอง + เรียง
INSERT INTO entries (pn, op) VALUES ('A1', 'OP10');                -- เพิ่ม
UPDATE entries SET op = 'OP20' WHERE id = 5;   -- แก้ (ต้องมี WHERE!)
DELETE FROM entries WHERE id = 5;              -- ลบ (ต้องมี WHERE!)
CREATE TABLE ชื่อ (...);  ALTER TABLE ชื่อ ADD COLUMN ...;          -- สร้าง/เพิ่มคอลัมน์
```

### JavaScript (หน้าเว็บ)
```js
const x = 5;  let y = 'abc';                          // ตัวแปร
document.getElementById('in-pn').value               // อ่านค่าช่องกรอก
document.getElementById('btn-save').addEventListener('click', () => { ... });  // เมื่อกดปุ่ม
const res = await fetch('/api/entries');              // ขอข้อมูล (GET)
const data = await res.json();                        // แปลงเป็นข้อมูล
await fetch('/api/entries', { method: 'POST',         // ส่งข้อมูล (POST)
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ pn: 'A1' }) });
list.map(e => `<div>${e.pn}</div>`).join('')          // แปลงข้อมูลเป็น HTML
```

### Node.js + Express (เซิร์ฟเวอร์)
```js
require('dotenv').config();                // อ่าน .env
const express = require('express');
const app = express();
app.use(express.json());                   // อ่าน JSON จากหน้าเว็บ
app.use(express.static('public'));         // ส่งไฟล์หน้าเว็บ
app.get('/api/x', (req, res) => res.json({ ok: true }));   // ดู
app.post('/api/x', (req, res) => { req.body; ... });       // รับข้อมูล
app.delete('/api/x/:id', (req, res) => { req.params.id; ... }); // ลบตาม id
db.query('SELECT * FROM entries WHERE id = ?', [id], (err, rows) => { ... }); // สั่ง MySQL
app.listen(3000);                          // เปิดเซิร์ฟเวอร์
```
